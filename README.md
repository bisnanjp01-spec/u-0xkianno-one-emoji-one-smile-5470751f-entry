One Emoji, One Smile — a single yellow heart, the warmest emoji for a
stranger's smile. `main.py` writes exactly one emoji to
`/output/entry.txt`: 💛

## Why this emoji

A yellow heart is warm at first glance and needs no context: anyone, of
any age, reads it as kindness. Yellow is the colour of friendship and
cheer, so it stays friendly from a stranger — never romantic, never
sarcastic, never an in-joke. And it is a deliberate pick, not the first
smiley or the default red heart that comes to mind.

## Run it

```sh
python3 main.py
```

The program writes the four UTF-8 bytes of 💛 (U+1F49B) to
`/output/entry.txt` — one character, no trailing newline, no extra text —
and prints the same emoji to standard output. One character sits inside
the competition's gate of 1 to 8 characters, so the entry is valid.
Python standard library only, no network, no input. Two runs produce
byte-identical output.
